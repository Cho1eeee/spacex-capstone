引言：项目背景与问题陈述

背景。SpaceX 以「火箭重复使用」颠覆了航天发射经济学。Falcon 9 的一级火箭可返回地面/海上平台并再次飞行，这是其报价远低于传统一次性火箭的根本原因。

问题陈述。如果能够根据发射参数（载荷质量、轨道类型、发射场、箭体状态等）预测一级火箭能否成功回收，就可以：

  • 为火箭复用调度与保险定价提供依据；
  • 识别影响回收成功的关键因素。

数据科学框架。将其建模为二分类问题：

Class 1 = 着陆成功  |  Class 0 = 着陆失败

数据来源：SpaceX REST API v4（发射、火箭、着陆场、载荷四个端点），辅以网页爬虫获取公开发射列表交叉验证。

时间跨度：2010–2020 年 Falcon 9 全部 90 次发射（含着陆尝试期完整数据）。

数据清洗方法（Data Wrangling）

1. 标签工程

  • Outcome（如 True ASDS / False Ocean / None None）→ 二分类标签 Class（1 成功 / 0 失败），并生成 LandingAttempt 标记。

2. 缺失值处理

  • 载荷质量缺失 → 用同箭体型号均值填充；LandingPad 缺失 → "Unknown"。

3. 类型与日期

  • date_utc → datetime，派生 Year 特征用于趋势分析。

4. 特征编码

  • 对 Orbit / LaunchSite / LandingPad / Serial 做独热编码（One-Hot），得到 82 维特征矩阵。
  • 保留物理特征：PayloadMass、Flights（复用次数）、GridFins、Reused、Legs、Block、ReusedCount。

输出：

  • dataset_part_2.csv：带标签清洗数据（90×20）
  • dataset_part_3.csv：机器学习特征矩阵（90×82）

使用 SQL 的探索性分析（SQLite）

清洗数据载入 SQLite（SPACEXTBL），执行 8 组查询，覆盖发射场、有效载荷、成功率、排名、时间维度：

  • 发射场：DISTINCT LaunchSite → 3 个场址
  • 有效载荷：0–10000 kg 载荷总质量；4000–6000 kg 明细；各轨道平均载荷
  • 成功率排名：KSC LC-39A 77.3% ＞ VAFB SLC-4E 76.9% ＞ CCAFS SLC-40 60.0%
  • 箭体排名：B1049 6 次着陆全部成功，B1051 5/5，B1059 4/4
  • 时间分析：2017 年 18 次发射成功率 83.3%，2020 年 19 次达 84.2%
SELECT LaunchSite,
  COUNT(*) AS Attempts,
  SUM(Class) AS Successes,
  ROUND(100.0*SUM(Class)/COUNT(*),1)
    AS SuccessRate
FROM SPACEXTBL
GROUP BY LaunchSite
ORDER BY SuccessRate DESC;
→ KSC LC 39A | 22 | 17 | 77.3
→ VAFB SLC 4E | 13 | 10 | 76.9
→ CCAFS SLC 40 | 55 | 33 | 60.0

结论、最佳模型解释与创新见解

最佳模型解释。max_depth=2 的决策树以 88.9% 测试准确率胜出，且仅用 2–3 个关键特征即可达到高精度，说明回收成败由少数强特征主导（箭体版本/复用状态、轨道、发射场）。树结构可解释、可审计，适合安全相关决策。

结论。

  • 一级火箭回收成功可预测，轻量模型即达 ~89% 准确率；
  • KSC LC-39A 与 VAFB 场址成功率显著高于 CCAFS SLC-40（承担早期试验发射）；
  • 成功率提升由技术迭代驱动（Block 5 时代 >84%），而非载荷变轻。

创新性 / 创造性见解。

  • 双重交叉验证的数据管线：API 主源故障时自动降级 + 独立实时 API 复核，比单一数据源更稳健；
  • 区位量化：用 Folium 将发射场与海岸线/铁路/城市的邻近距离量化，解释选址的回收经济学；
  • 可解释优先：小深度决策树优于复杂模型，提示本问题中"少即是多"；
  • 后续工作：接入实时 SpaceX API 增量更新；引入天气与-downrange 距离特征；以 SHAP 做特征归因。
